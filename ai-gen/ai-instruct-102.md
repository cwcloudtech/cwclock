# AI instruction 102

## Api keys

### File

I want the table of the api keys to have a download button which will download from an api endpoint `GET /me/config/file` a `config` file containing (that can be imported from the cli):

```
api_url = {CWCLOCK_API_URL}
api_key = {selected api key}
org_id = {first organization of the user}
```

The endpoint can optionaly take an argument `?organization={uuid}` if it's present it will add in the file:

```
org_id = {current selected org id}
```

And the frontend can pass it.

## QR code

### QR codes

On the same model, I want a the table of the API keys to have a button "eye" which will display a QR code containing the same content of the previous file.

This QR code must be generated by an API endpoint `GET /me/config/qr` (same with optional `?organization={uuid}`).
