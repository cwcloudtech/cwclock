# AI instruction 101

## Cli

### All day

In the record command I want also the `--all-day` option.
If `--from` or `--begin` is specified it's the entire day of the date specified.

### New format

Accept `YYYY-MM-DD` also (put `00:00:00` in begin date if it's not specified and `23:59:59` for the end date if it's not specified).

For all command with `--begin/--end` or `--from/--to`.
